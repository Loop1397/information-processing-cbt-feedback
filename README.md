# 정보처리기사 실기 CBT — 사용 안내

본 사이트는 정보처리기사 실기 복원 문제를 CBT 형식으로 풀어볼 수 있도록 제공하는 비공식 웹앱입니다. 한국산업인력공단, Q-Net 또는 시험 출제 기관과 제휴·승인·연관되어 있지 않습니다.

## 사용 방법

1. 회차 목록에서 연도와 회차를 선택합니다. 연도별 필터와 출제 연도순·합격률순 정렬을 이용할 수 있습니다.
2. 각 문제에 대한 답을 작성합니다(서술형 문항은 답안을 적고 해답을 확인할 수 있지만 점수에는 포함되지 않습니다).
3. 제출하기를 눌러 자동 채점 결과와 문항별 정답 및 해설을 확인합니다.

## 유의 사항
- 실제 정보처리기사 실기 시험은 필답형으로 진행되므로, 시험 방식과 환경이 본 사이트와 다를 수 있습니다.
- 실제 시험 내용과 다르거나 일부 내용이 누락되었을 수 있습니다. 또한 해설은 학습을 돕기 위해 작성된 참고 설명으로, 공식 해설을 의미하지 않습니다. 답이나 설명이 정확하지 않다고 생각되면 관련 교재나 신뢰할 수 있는 자료를 함께 확인해 주세요.
- 자동 채점은 등록된 답안 기준으로 동작합니다. 의미가 같더라도 등록되지 않은 동의어나 표현은 오답으로 처리될 수 있으며, 공식 채점 결과가 아닙니다.
- 버그나 문제 오류, 개선 사항은 [공개 이슈](https://github.com/Loop1397/information-processing-cbt-feedback/issues/new/choose)에서 제보해 주세요.

## 릴리스 기록
