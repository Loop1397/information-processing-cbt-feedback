# 정보처리기사 실기 CBT — 사용 안내

정보처리기사 실기 복원 문항을 풀고 제출 후 정답과 해설을 확인하는 비공식 학습 도구입니다. 한국산업인력공단, Q-Net 또는 시험 출제기관과 제휴·승인·연관되어 있지 않습니다.

## 사용 방법

1. 회차 목록에서 연도와 회차를 선택합니다. 연도별 필터와 출제 연도순·합격률순 정렬을 이용할 수 있습니다.
2. 객관식·단답형 입력란에 답을 작성합니다. 서술형 문항은 답안을 적고 해답을 확인할 수 있지만 점수에는 포함되지 않습니다.
3. 제출하기를 눌러 자동 채점 결과를 확인합니다. 채점 대상 문항은 각 1점이며, 이 도구의 합격 표시는 12점 이상을 기준으로 합니다.
4. 결과 화면에서 문항별 정답·해설을 확인하고, 이 회차 다시 풀기 또는 회차 목록으로 돌아가기를 선택합니다.

자동 채점은 등록된 답안 기준으로 동작합니다. 의미가 같더라도 등록되지 않은 동의어나 표현은 오답으로 처리될 수 있으며, 공식 채점 결과가 아닙니다.

## 자료와 정확성

복원 문항과 해설은 응시자 기억 및 확인 가능한 공개 자료를 바탕으로 정리되어 실제 시험 문구·정답·해설과 다를 수 있습니다. 학습 참고용으로만 이용하고, 공식 자료나 채점 기준으로 간주하지 마세요.

문항·정답·해설·통계 오류는 [공개 이슈 제보 양식](https://github.com/Loop1397/information-processing-cbt-feedback/issues/new/choose)으로 알려 주세요. 회차와 문항 번호, 오류 설명, 확인 가능한 공개 출처 URL을 적고, 전체 시험문제·PDF·스캔 이미지·개인정보는 복사하거나 첨부하지 마세요.

## 릴리스 기록

공개 변경 사항은 이 저장소의 Releases 탭과 CHANGELOG.md에서 확인할 수 있습니다.

## 저작권·개인정보 관련 연락

공개 이슈에 개인정보나 권리자 연락처를 남기지 마세요. 공개 이슈에 민감한 정보가 포함된 경우 내용을 더 게시하지 말고 저장소 관리자의 GitHub 비공개 연락 수단으로 알려 주세요. 권리 허락이 확인되지 않은 원문 문제지·PDF·이미지 복제물은 이 저장소나 릴리스에 올리지 않습니다.

## 제보 시 주의사항

이슈는 공개됩니다. 실명, 이메일, 계정 정보, 비밀 정보와 전체 시험문제는 입력하지 마세요. 문제 오류를 확인할 수 있는 최소한의 설명과 공개 출처 링크만 제공해 주세요.
